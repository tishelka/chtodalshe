# ЧтоДальше

Мобильное приложение на React Native / Expo и классический backend на **FastAPI + PostgreSQL**. Приложение предлагает одну идею досуга под участников, время, бюджет, место, настроение и интересы. Сохраняет избранное, историю и выбранные планы. Регистрация не обязательна: сервер создаёт анонимную сессию.

Все прежние пользовательские сценарии сохранены: приветствие и пропуск интересов, четыре вкладки, подбор, «Другое» без повторов, «Удиви меня», повтор последних условий через форму, профиль и очистка истории с подтверждением. Каталог содержит 70 занятий в 10 категориях. Локальный демонстрационный режим работает без сервера.

## Быстрый запуск через Docker

Нужны запущенный Docker Desktop с Linux-контейнерами и Node.js >= 22.13.

```sh
npm ci
docker compose up --build -d
```

Compose запускает PostgreSQL 18 и FastAPI. Перед запуском API автоматически применяются миграции Alembic и загружается каталог. Данные PostgreSQL хранятся в именованном volume; повторный запуск обновляет каталог и не очищает личные данные.

Создайте `.env` в корне проекта:

```dotenv
EXPO_PUBLIC_API_URL=http://localhost:8000
```

Затем:

```sh
npm run start -- --clear
```

- API: `http://localhost:8000`
- Swagger: `http://localhost:8000/docs`
- Проверка API и базы: `http://localhost:8000/health`
- Остановка контейнеров: `docker compose down` — volume сохраняется.

Пароль `whatnext` в Compose — значение для локальной разработки. Параметры серверной базы относятся только к backend и не передаются мобильному клиенту. Для другого окружения настройте `DATABASE_URL`, пароль базы и допустимые CORS-адреса; при публикации API используйте HTTPS.

## Адрес API на устройстве

| Где открыто приложение       | EXPO_PUBLIC_API_URL             |
| ---------------------------- | ------------------------------- |
| Браузер на том же компьютере | `http://localhost:8000`         |
| Android Emulator             | `http://10.0.2.2:8000`          |
| iOS Simulator на Mac         | `http://localhost:8000`         |
| Физический телефон           | `http://LAN_IP_компьютера:8000` |

Телефон и компьютер должны быть в одной сети. FastAPI слушает `0.0.0.0:8000`. Для браузера на другом адресе добавьте его origin в `CORS_ORIGINS`. После изменения `.env` перезапустите Expo с `--clear`. URL API — публичная настройка, ключи базы в нём не нужны.

```sh
npm run android
npm run web
npm run ios
```

Для Android-эмулятора нужны Android Studio и запущенное виртуальное устройство. iOS Simulator требует macOS/Xcode; на Windows можно использовать физический iPhone с совместимым Expo Go. Первое получение приложения через Expo Go требует доступа к Metro.

## Backend без Docker

Нужны Python >= 3.12 и PostgreSQL >= 16. Создайте отдельного пользователя и пустую базу `whatnext`, затем выполните из корня проекта:

```powershell
python -m venv backend/.venv
backend/.venv/Scripts/python.exe -m pip install -r backend/requirements-dev.txt
Copy-Item backend/.env.example backend/.env
```

В `backend/.env` укажите своё подключение:

```dotenv
DATABASE_URL=postgresql+psycopg://whatnext:whatnext@localhost:5432/whatnext
CORS_ORIGINS=["http://localhost:8081","http://127.0.0.1:8081","http://localhost:4174","http://127.0.0.1:4174"]
```

Сервер использует только PostgreSQL: SQLite и неявная подмена базы не предусмотрены. Пароль с особыми символами в URL подключения нужно кодировать как часть URL.

```sh
npm run backend:bootstrap
npm run backend:start
```

Первая команда применяет миграции и выполняет идемпотентное наполнение, вторая запускает Uvicorn. На Linux/macOS путь к Python виртуального окружения — `backend/.venv/bin/python`; npm-скрипты выбирают путь автоматически.

Низкоуровневые команды для работы из папки `backend/`:

```sh
python -m alembic upgrade head
python -m app.seed
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Используйте Python из созданного виртуального окружения. Новые изменения схемы оформляйте отдельными ревизиями Alembic. Bootstrap не сбрасывает базу.

## Текущее Windows-окружение

В рабочей папке установлен локальный Node.js 22, поскольку системный Node.js старее требований Expo. Доступен помощник:

```powershell
.\scripts\npm-local.ps1 run start -- --clear
.\scripts\npm-local.ps1 run backend:start
.\scripts\npm-local.ps1 run check
```

Он не меняет системную установку. Для нового клона с устаревшим Node.js можно предварительно выполнить `npm install --prefix .tools node@22`. При системном Node.js >= 22.13 используйте обычный npm.

При реализации создан отдельный локальный кластер PostgreSQL в `.tools/postgres/data`, порт **55432**, и проверена реальная связка с API на порту 8000. Его настройки записаны в исключённый из репозитория `backend/.env`. Существующие системные базы не менялись. Этот кластер — удобство текущего рабочего окружения; для нового клона основной способ запуска — Compose или собственный PostgreSQL.

Если этот локальный кластер остановлен, его можно запустить в отдельном терминале из корня текущего проекта:

```powershell
& "C:\Program Files\PostgreSQL\16\bin\postgres.exe" -D "$PWD\.tools\postgres\data" -p 55432 -h 127.0.0.1
```

## Локальный режим

Пустой или отсутствующий `EXPO_PUBLIC_API_URL` включает демонстрационный режим. Его каталог и все личные данные хранятся на устройстве. Подбор, история, избранное и интересы работают без backend.

В серверном режиме данные хранятся через HTTP API в PostgreSQL. При недоступном сервере отображается ошибка, повторная попытка и кнопка явного перехода в деморежим. В профиле можно вернуться к серверу. Данные режимов не смешиваются. Существующий формат локальных данных и ключ `whatnext.demo.v1` сохранены.

Алгоритм рекомендаций остаётся в чистом TypeScript-модуле приложения. Интересы и настроение влияют на score; участники, время, бюджет на человека и место — жёсткие ограничения. «4 часа и больше» снимает верхний лимит времени. «Удиви меня» не переносит ограничения прошлой формы.

## API и хранение

Backend состоит из пяти групп маршрутов и проверки здоровья, всего 13 HTTP-операций. Подробный контракт: [backend/API.md](backend/API.md).

- Каталог доступен на чтение без токена.
- Анонимная сессия создаётся через `POST /sessions/anonymous`.
- Для `/me/*` нужен `Authorization: Bearer <accessToken>`.
- Пользователь определяется сервером, а не переданным клиентом ID.
- Токен сохраняется на устройстве отдельно для каждого URL API; в базе хранится только его SHA-256.
- Избранное имеет уникальную пару пользователь/занятие. История сохраняется с устойчивым UUID; повтор PUT не создаёт дубликат и не снимает отметку выбора.
- Списки читаются страницами по 500 записей клиентом; API допускает limit от 1 до 500.

Анонимная сессия в MVP действует до удаления соответствующей серверной записи. При потере токена восстановление аккаунта не предусмотрено. Недействительный токен не заменяется новым автоматически, чтобы не создавать впечатление, что личные данные исчезли.

```text

  components/                общий интерфейс

    database.py              подключения и сессии PostgreSQL

    seed.py                  импорт общего каталога
```

## Изменение каталога

Единственный исходный набор данных — `src/data/catalog.ts`. Сохраняйте числовые коды существующих занятий, чтобы не менять UUID.

```sh
npm run seed:generate
npm run seed:check
npm run backend:bootstrap
```

Генератор выпускает `backend/data/activities.json`; проверка выявляет расхождение. Python валидирует записи и обновляет их через PostgreSQL upsert. Он не удаляет пользователей и историю. Архивирование занятия выполняется через `isActive: false`.

## Проверки

```sh
npm run check
npm run backend:lint
npm run backend:test
npx playwright install chromium
npm run test:e2e
npm run test:remote-ui
npm run export:native
npx expo-doctor
```

`backend:test` требует запущенного PostgreSQL и прав создания тестовой базы. Тесты создают отдельную базу со случайным именем, применяют настоящие миграции, а затем удаляют только эту тестовую базу. Они не очищают рабочую базу. Для отдельного тестового сервера можно установить `TEST_DATABASE_URL`.

`test:e2e` собирает демоверсию с пустым URL API независимо от `.env`. `test:remote-ui` требует запущенного FastAPI и проверяет реальную серверную версию, а также ошибки соединения. По умолчанию тестовый API — `http://127.0.0.1:8000`; другой адрес задаётся через `TEST_API_URL`, а origin `http://127.0.0.1:4174` должен быть разрешён CORS.

При использовании установленного в рабочей папке Chromium:

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.tools\playwright"
.\scripts\npm-local.ps1 run test:remote-ui
```

Экспорт web находится в `dist/`, JS/Hermes-пакеты Android и iOS — в `.tools/native-export`. Эти экспорты не заменяют установку APK/IPA и проверку на физическом устройстве.
