# Контракт ЧтоДальше API

**FastAPI + PostgreSQL**, документация `/docs`, спецификация `/openapi.json`.

Все операции доступны без регистрации и токенов. Сервер использует один общий профиль: данные и изменения видны всем клиентам. Клиенту не нужно передавать `userId`.

## Маршруты

| Метод  | Путь                        | Ответ                                              |
| ------ | --------------------------- | -------------------------------------------------- |
| GET    | `/health`                   | `{"status":"ok"}`; 503 при недоступной БД          |
| GET    | `/activities`               | Массив занятий                                     |
| GET    | `/activities/{activity_id}` | Одно занятие или 404                               |
| GET    | `/preferences`              | Настройки общего профиля                           |
| PUT    | `/preferences`              | 204                                                |
| GET    | `/favorites`                | Массив UUID занятий                                |
| PUT    | `/favorites/{activity_id}`  | 204; повтор не создаёт дубликат                    |
| DELETE | `/favorites/{activity_id}`  | 204, в том числе при повторе                       |
| GET    | `/history`                  | Массив записей от новых к старым                   |
| PUT    | `/history/{entry_id}`       | 204; повтор не дублирует запись и сохраняет chosen |
| PATCH  | `/history/{entry_id}`       | 204; тело `{"chosen":true}`                        |
| DELETE | `/history`                  | 204; очищает историю общего профиля                |

Всего 12 операций. Списки принимают `offset >= 0` и `limit` от 1 до 500, по умолчанию 100. Каталог включает архивные записи для открытия старой истории; движок не рекомендует `isActive: false`.

## Настройки

`PUT /preferences`, заголовок `Content-Type: application/json`:

```json
{
  "interests": ["board_games", "walks"],
  "onboardingCompleted": true,
  "lastFilters": {
    "participants": 3,
    "availableMinutes": 120,
    "budgetPerPerson": 500,
    "location": "home",
    "mood": "calm"
  }
}
```

Список интересов может быть пустым; дубликаты удаляются. `lastFilters` может быть `null`. Числовой `null` в фильтрах снимает ограничение. Участники — от 1 до 10, время положительное, бюджет неотрицательный.

Места: `home`, `outdoors`, `venue`, `any`. Настроения: `calm`, `active`, `social`, `creative`, `any`. Категории: `movies`, `video_games`, `board_games`, `walks`, `sport`, `creativity`, `cooking`, `reading`, `culture`, `social`.

Пример запроса из терминала:

```sh
curl http://localhost:8000/preferences
```

## История

`PUT /history/30000000-0000-4000-8000-000000000001`:

```json
{
  "id": "30000000-0000-4000-8000-000000000001",
  "activityId": "10000000-0000-4000-8000-000000000001",
  "createdAt": "2026-10-12T12:00:00Z",
  "filters": {
    "participants": 1,
    "availableMinutes": null,
    "budgetPerPerson": null,
    "location": "any",
    "mood": "any"
  },
  "chosen": false
}
```

ID в теле должен совпадать с адресом. Дата содержит часовой пояс и нормализуется в UTC. Одна активность может иметь несколько записей с разными ID. Повтор PUT с тем же ID оставляет ранее записанный результат, включая отметку выбора.

## Ошибки

- 404 — занятие или запись истории не найдены.
- 422 — неверные значения, лишние поля, UUID или дата.
- 409 — нарушено ограничение базы.
- 503 — база временно недоступна.

Ответ содержит `detail`. Формат полей JSON — camelCase; Python и таблицы используют snake_case. Неуспешный ответ не означает, что запрос можно молча считать выполненным: приложение показывает повторную попытку.
